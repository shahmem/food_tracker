# Ghazal — South 11

Shared expense tracker for splitting bills, tracking stock, and settling balances.

## Stack
- Node.js + Express
- SQLite (better-sqlite3)
- Vanilla JS + Tailwind CSS

## Run

```bash
npm install
node server.js
```

Open [http://localhost:3000](http://localhost:3000).

## Login

Default credentials: `yourname` / `yourname@123`
